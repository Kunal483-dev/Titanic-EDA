# Titanic EDA

This is a beginner-level Exploratory Data Analysis project on the Titanic dataset.

I used Pandas, Matplotlib, Seaborn, and Plotly to understand the data and survival patterns.

## What I did

- Loaded and checked the cleaned dataset
- Created summary statistics
- Made histograms and boxplots
- Analyzed survival by gender and passenger class
- Created a correlation heatmap and pairplot
- Created a FamilySize feature

## Main Findings

- Female passengers had a higher survival rate.
- First-class passengers had better survival chances.
- Fare contains some outliers.
